# Guardrail Ablation Study

**How much does the layer between your bot and the exchange actually change the tail?**

A fully public, reproducible empirical study: public market data, public code, every number in the write-up regenerated by one command.

> Status: pre-publication draft. English write-up: [`ARTICLE.md`](ARTICLE.md). 中文说明: [`README.zh-CN.md`](README.zh-CN.md).

---

## Headline result

10 Binance USDT-M perpetuals × 5 deliberately naive strategies = 50 combinations, 1-hour bars, 2022-01-01 → 2025-12-31, with taker fees, slippage and real funding settlements applied.

| Configuration | Mean total return | Ruin rate | Daily CVaR(5%) | Note |
|---|---|---|---|---|
| `control` — 5x, no rules | −100% | **82%** | −60.9% | 41 of 50 accounts hit zero |
| `cap_1x` — exposure cap only | −78.2% | 18% | −9.9% | remaining ruin = 1x shorts squeezed |
| `kill_5pct` — daily kill switch only | −99.6% | 14% | −18.2% | 33,178 halts; ruin traded for slow bleed |
| `all` — cap + kill switch | −72.3% | **0%** | −6.7% | no account hit zero |
| `dup_nodedupe` — duplicate orders executed | −85.1% | 34% | −12.3% | mean peak 3.9x, worst 10.2x; all 50 above 2x |
| `dup_dedupe` — duplicate orders blocked | −78.2% | 18% | −9.9% | back to the 1x baseline |

Three things the data supports:

1. **The exposure cap does almost all of the work.** Ruin 82% → 18%; CVaR −61% → −10%.
2. **A cap alone is not enough.** Every remaining failure at 1x was a short position; 7 of 9 were the funding-carry strategy shorting into rallies. Cap + kill switch: 0/50.
3. **Idempotency is not cosmetic.** Re-executing 10% of orders pushed **all 50 accounts above 2x** (mean peak 3.9x, worst 10.2x) and moved ruin from 18% to 34%.

And the result nobody wants to publish: **a daily kill switch on its own, at 5x, made returns worse.** At that leverage a −5% daily limit is a ~1% price move, so the breaker fires on noise (33,178 times). Lower the leverage first; the breaker is for the outlier, not the ordinary Tuesday.

**These strategies have no alpha, on purpose.** With fees, slippage and funding set to zero (`run.py run --gross`) the `cap_1x` arm still returns −45% and the uncapped 5x arm still ends at −100%. The study measures how an account dies, not how to make one rich.

## Study design

| Field | Setting |
|---|---|
| Venue / product | Binance USDⓈ-M perpetual futures |
| Timeframe | 1h, 2022-01-01 → 2025-12-31 (UTC) |
| Symbols | BTC, ETH, SOL, BNB, XRP, DOGE, ADA, AVAX, LINK, ARB (USDT-margined) |
| Starting equity | $10,000 per (symbol × strategy), isolated |
| Costs | 5 bps taker + 2 bps slippage per side, market orders |
| Funding | Applied at real 8h settlement times |
| Execution | Signal on bar close, filled at **next bar open**; no look-ahead |
| Sizing | Fixed at entry, not rebalanced bar-by-bar |

Bar count: 339,921 per strategy (ARB starts 2023-03-23) → ~1.7M hourly bars in total.

### Strategies (all naive, all public)

1. `ma_trend` — 20/60 moving-average crossover, long/short
2. `bollinger_mr` — 20-period, 2σ mean reversion
3. `donchian` — 20-bar breakout in, 10-bar exit
4. `funding_carry` — hold the side that collects the trailing 24h funding
5. `random_entry` — random entries (luck control, fixed seed)

`buy_hold` is carried as a benchmark and excluded from the strategy averages.

### Experiment 1 — leverage cap and daily kill switch

| Config | Leverage | Exposure cap | Daily kill switch |
|---|---|---|---|
| `control` | 5x | — | — |
| `cap_1x` | 5x | 1x | — |
| `kill_5pct` | 5x | — | −5% of day-start equity |
| `all` | 5x | 1x | −5% of day-start equity |

The kill switch flattens the position and freezes the account until the next UTC day. It is a circuit breaker, not a stop-loss.

### Experiment 2 — order idempotency

| Config | Duplicate rate | Dedupe window | Leverage |
|---|---|---|---|
| `dup_nodedupe` | 10% | off | 1x |
| `dup_dedupe` | 10% | 30 s | 1x |

Both arms sit at 1x so the only difference is whether re-sent orders execute. Duplicates simulate retrying webhooks and double-firing strategies.

**Ruin** = equity touched zero and the position was liquidated on that bar.

### Metrics

Total return, CAGR, max drawdown, Calmar, Sharpe, daily CVaR(5%), worst day, ruin rate, orders, blocked duplicates, cap rejections, kill-switch halts, peak gross leverage.

## Reproduce

Requires Python 3.13 and public network access to the Binance REST API. No API key, no account.

```bash
uv venv
uv pip install -r requirements.txt
source .venv/bin/activate        # Windows: .venv\Scripts\activate

python run.py download           # ~60 MB of klines + funding, gzip-cached under data/
python run.py validate           # asserts zero gaps in every series
python run.py run                # full matrix -> results/*.csv
python run.py run --gross        # same signals, zero costs, as a control
python -m unittest discover -s tests -v
python check_numbers.py          # every number in README/ARTICLE vs results/*.csv
```

Optional figures (needs `requirements-figures.txt`):

```bash
uv pip install -r requirements-figures.txt
python figures.py                # results/figures/*.png (SVGs are written but not committed)
```

The PNGs are byte-reproducible; matplotlib's SVG output is not (random clip-path ids), so only PNGs are tracked. `check_numbers.py` verifies every figure the article references actually exists.

Subset runs write to `results/*_subset.csv` and never overwrite the published tables:

```bash
python run.py run --symbols BTCUSDT --start 2024-01-01T00:00:00Z
```

### Reproducibility contract

`results/run_meta.json` records the study version, seed, every cost parameter, the full config matrix and library versions. Two runs with the same seed produce byte-identical summary CSVs (SHA-256 verified). A published table is only valid if its `run_meta.json` matches the commit you are reading.

## What this does not model

- **Liquidation is simplified** to "the intrabar adverse extreme took equity to zero". No partial liquidation, insurance fund, ADL or exchange-specific maintenance margin. Real liquidations are usually worse, not better.
- **No order-book depth.** One fixed slippage number for every symbol and hour.
- **No operational failures** — rejected orders, rate limits, disconnects, partial fills. Those are the failure modes a guardrail layer exists for, and they are not measured here: this study measures policy, not plumbing.
- **One regime, ten symbols, four years.** 2022 was a bear market; 2023–2025 was a recovery.
- **No parameter search.** Textbook settings, fixed. Tuning would turn an ablation into a curve fit.
